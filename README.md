# Holberton School — C#

Ce repository regroupe l'ensemble des projets réalisés dans le cadre du cursus **C#** de Holberton School : des bases du langage jusqu'aux concepts avancés de programmation orientée objet et aux structures de données.

Chaque dossier correspond à un module du cursus, avec son propre README détaillant les exercices qu'il contient.

## Sommaire des projets

| # | Projet | Description | Concepts clés |
|---|---|---|---|
| 1 | [`csharp-hello_world`](./csharp-hello_world) | Premiers pas en C# : création et exécution d'un projet. | Syntaxe de base, variables, `Console.WriteLine`, types simples |
| 2 | [`csharp-ifelse_loops_methods`](./csharp-ifelse_loops_methods) | Logique de contrôle et fonctions. | Conditions `if/else`, boucles, méthodes |
| 3 | [`csharp-arrays_lists_dictionaries`](./csharp-arrays_lists_dictionaries) | Manipulation des principales collections de données. | Tableaux, `List`, `Dictionary` |
| 4 | [`csharp-structs_enums`](./csharp-structs_enums) | Types de données personnalisés simples. | `struct`, `enum` |
| 5 | [`csharp-classes`](./csharp-classes) | Introduction à la programmation orientée objet. | Classes, namespaces, attributs, constructeurs |
| 6 | [`csharp-inheritance`](./csharp-inheritance) | Réutilisation et hiérarchie de classes. | Héritage, classes abstraites, principe de Liskov |
| 7 | [`csharp-interfaces`](./csharp-interfaces) | Contrats de comportement entre classes. | Interfaces, classes abstraites vs interfaces, mot-clé `as` |
| 8 | [`csharp-exceptions`](./csharp-exceptions) | Gestion des erreurs à l'exécution. | `try/catch`, levée d'exceptions personnalisées |
| 9 | [`csharp-generics`](./csharp-generics) | Implémentation d'une file générique. | Génériques, file (`Queue`) via liste chaînée maison |
| 10 | [`csharp-delegates_events`](./csharp-delegates_events) | Programmation événementielle. | Délégués, méthodes anonymes, événements, callbacks |
| 11 | [`csharp-hashset_stack_queue_linkedlist`](./csharp-hashset_stack_queue_linkedlist) | Structures de données natives du framework .NET. | `HashSet`, `Stack`, `Queue`, `LinkedList` |
| 12 | [`csharp-linear_algebra`](./csharp-linear_algebra) | Calculs vectoriels appliqués à la programmation. | Vecteurs 2D/3D, magnitude, produit scalaire |
| 13 | [`csharp-text_based_interface`](./csharp-text_based_interface) | Mini-application de gestion d'inventaire en console. | Architecture logicielle, interaction utilisateur en mode texte |

## Outils & technologies

- **C#** comme langage principal
- **.NET** comme framework d'exécution
- **Git / GitHub** pour le versionnage et la publication du code
